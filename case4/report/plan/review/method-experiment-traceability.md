# 方法与实验对应

| 方法 | 实验或局限 | 允许结论 |
|---|---|---|
| Q8灰度 | [8]全格式穷举；[5]RGB565 RTL test | 指定输入域连续误差小于1LSB；按真实测试范围说RTL一致 |
| 双行窗口 | tap scoreboard及完整帧输出数量 | 窗口内容/坐标覆盖到的case通过；非所有动态帧场景证明 |
| 中值/Sobel/阈值/overlay | 小帧整数参考与边界case | 已测样本一致；非图像检测准确率 |
| 中值级联 | 小帧数值/640计数、OOC资源 | 可量化当前资源开销；大帧逐码与时序仍待补 |
| XPM适配 | Xilinx仿真、OOC；Efinix未测 | 仅当前厂商后端证据 |
| 整机系统 | 摄像头、HDMI、CDC、DDR、功耗未测 | 仅设计规划，不写已验证 |
