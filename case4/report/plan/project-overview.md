# 赛题四设计报告写作计划

## 已知范围

- 文档类型：中文 FPGA 竞赛工程设计报告，不是期刊投稿论文。
- 暂定题目：基于 FPGA 的实时图像边缘检测系统设计与验证。
- 输出：case4/report/赛题四_系统设计与验证报告.md，用户后续自行排版为 Word。
- 技术范围：现有 Python Golden、RGB565/RGB888 定点灰度、窗口与行缓存、中值、Sobel、阈值、叠加算子、算子级集成与已有验证证据。
- 系统范围：摄像头、显示、跨时钟域、板载交互和 DDR 等仅说明规划；尚未实现部分留空，不生成系统顶层 RTL。
- 数据原则：区分算法推导、既有测试记录、本轮复核与尚未实测；不得编造板级帧率、频率、功耗或 Ti60 资源数据。
- 未完成标记：统一使用“【待完成】”并写明待补内容；允许留出图、表和文字位置，不使用模拟数据替代实测。
- 当前阶段：用户已确认题目、章节结构和一次性交付方式，进入S1/S2/S3证据核对与分章撰写。

## 写作依据

以 8.22 更正版赛题解读、原始选题指南、当前 RTL、Golden、测试脚本和原始报告为依据。既有架构说明可能存在旧描述，应以代码及验证证据纠正后写入报告。
