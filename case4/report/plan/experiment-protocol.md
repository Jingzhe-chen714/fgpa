# 实验与结果口径

- 数据：RGB565全65536码；RGB888全16777216组合；既有经典图像与合成图；8×6自检帧；640×480栅格。算法非训练模型，无训练/验证划分、Non-IID或类别不平衡统计任务。
- 对照：RTL对同一定点Golden；连续灰度参考用于量化误差；有/无中值仅比较图像表现与资源，不宣称未经标注评估的精度提升。
- 指标：最大/平均连续灰度误差、逐像素数值与坐标/标记一致性、有效窗口数量、OOC资源、尚待测量的时序/吞吐/延迟/功耗。
- 既有资源记录：Vivado2023.1，xc7a35tcpg236-1，640×480，RGB565默认；基础296LUT/404FF/2RAMB18，中值822/610/4，DSP均0。没有用户时序约束；不报告Fmax成功。
- 本轮将重跑轻量Golden测试与选择性XSIM验证，原始输出放report/verification；是否通过必须等主代理核验，不预填。
- 验证缺口：实图RTL全帧逐码、中值大帧逐码、连续多帧/随机空拍/帧中复位、动态阈值、目标厂商RAM碰撞语义、约束与实现、实际采集/显示。
- 可解释性：无XAI贡献，相关统计不适用。效率与消融以明确配置和现有报告陈述，不伪造重复实验标准差。
- 未完成数据：按用户要求留【待完成】和空位，不生成mock数据。
